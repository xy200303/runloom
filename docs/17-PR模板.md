# PR 模板

将以下内容复制到仓库的 `.github/pull_request_template.md`，或在实现阶段直接将本文件作为模板来源。

```md
## Summary

-

## Changed Packages

- [ ] runloom-agent
- [ ] runloom-tui
- [ ] runloom-web
- [ ] docs only
- [ ] CI/release only

## Change Type

- [ ] Fix
- [ ] Feature
- [ ] Refactor
- [ ] Docs
- [ ] Test
- [ ] Breaking change
- [ ] Security-sensitive change

## Public API Impact

- [ ] No public API change
- [ ] Adds public API
- [ ] Changes public API
- [ ] Removes public API
- [ ] Changes exports
- [ ] Changes RunloomEvent schema

Notes:

## Runtime / Safety Impact

- [ ] Model provider
- [ ] Tool execution
- [ ] Approval
- [ ] Session/store
- [ ] Todo/event stream
- [ ] Skills
- [ ] MCP
- [ ] A2A
- [ ] External agent
- [ ] Memory/growth
- [ ] Self-evolution/evals
- [ ] npm publish/CI

Risk notes:

## Verification

- [ ] Typecheck
- [ ] Tests
- [ ] Build
- [ ] Pack dry run
- [ ] Eval benchmark, if required
- [ ] Manual TUI check, if required
- [ ] Manual Web check, if required

Commands/results:

## Docs / Examples

- [ ] README updated
- [ ] Examples updated
- [ ] Docs updated
- [ ] Changeset added
- [ ] Not needed

## Security Checklist

- [ ] Does not commit secrets or local user data
- [ ] Does not bypass permission policy
- [ ] Does not bypass approval
- [ ] Does not bypass audit trail
- [ ] Redaction considered
- [ ] Rollback considered for high-impact changes
- [ ] No mock data outside test code, test fixtures, or test helpers

## Screenshots / Logs

Add screenshots or relevant logs for UI changes.

## Notes for Reviewer

-
```
