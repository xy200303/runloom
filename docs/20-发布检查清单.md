# 发布检查清单

本文档用于发布 `runloom-agent` 和 `runloom-tui` 前的人工确认。`runloom-web` 首期不发布，后期 Vue 实现完成后再纳入清单。

## 发布前检查

- 工作区干净，没有未提交代码、生成物、日志或本地配置。
- 每个影响发布包的 PR 都包含 changeset；仅文档、测试或根工具变更可以不写 changeset。
- `CHANGELOG.md` 和包级 changelog 由 Changesets release PR 更新。
- `docs/02-TODO清单.md` 已同步当前实现状态。
- README、examples、exports、types 和 package `files` 白名单与实际发布内容一致。
- 没有提交密钥、`.env`、本地数据库、`~/.runloom` 用户数据或真实私有日志。

## 必跑命令

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm test:vitest
pnpm test:e2e
pnpm pack:dry
pnpm publish:dry
```

## 包内容确认

- `runloom-agent` 只发布 `dist`、`README.md`、`examples` 和必要 package metadata。
- `runloom-tui` 只发布 `dist`、`README.md`、`examples`、CLI bin 和必要 package metadata。
- `runloom-web` 不出现在首期 workspace 发布命令中。
- 包内不包含 `src`、测试、docs、临时 state、coverage 或构建缓存。

## 发布保护

- 只允许从 `main` 分支发布。
- 发布前先合并 Changesets release PR。
- 发布失败后不要覆盖 npm 版本；修复后发布新的 patch 版本。
- 如出现严重问题，使用 npm deprecate 标记问题版本，并发布修复版本。

## 发布后检查

- npm 包页面显示正确版本、README 和 bin。
- 临时 Node.js 项目可以 import `runloom-agent`。
- 临时 Node.js 项目可以运行 `runloom` CLI。
- CI 工作流保持通过。
